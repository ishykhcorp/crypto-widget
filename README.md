## Requirements

| Functional requirements                                 | Non-functional requirements                              |
| ------------------------------------------------------- | -------------------------------------------------------- |
| Widget should easily inject in any page or app          | Widget should be responsive for web and mobile platforms |
| There can be multiple instances of widgets              | Widget should show reliable data                         |
| User can select coin and interval to track price change | Widget should provide neat and obvious UX                |
| Widget should have theme toggle                         |                                                          |
| Widget should have 2 modes: compact and full            |                                                          |
